## 范围与完成定义

- 范围：本地同屏轮流操作；16–33 双人选关；双人关卡加载；红蓝两队人类回合；胜/负/平局、胜局计数、重开和退出；相应 UI/音频/镜头反馈。
- 与单人进度隔离：双人选关无需解锁；双人胜负不写单人分数或关卡解锁。原版分支依据 `Team2.aiControlled`，复刻应以显式会话模式驱动，不从 XML `players` 或关卡编号反推用户选择。
- 完成定义：每条 `2P-*` 规则有可追溯来源、实际生产入口、自动回归或 Play Mode 用例以及已执行结果；菜单→选关→战斗→双方回合→三种结算→重开/退出均跑通；16–33 的 XML 与预览逐项核验。缺失原版数据时只能标记对应关卡待确认，不伪造或用单人关卡代替原版并宣称一致。
