# 手柄双扳机力度规格（2026-09-26）

本规格在实现前建立，验收结果按实际运行更新。来源是用户本轮授权的新手柄操作；替代旧版 RT 深度直接指定力度的规则。原版 `Solid.as::twang/drawTwangLine` 的拖动方向、最小距离、20/30 力上限与库存/回合规则仍通过共享生产入口执行。

## 验收口径

- 用真实 Input System 虚拟 Gamepad 事件驱动生产 CaptureInput/Update，不通过手动设置 ControllerPower 或改写公式证明通过。
- 当前隔离 Unity 6000.6.0f1 图形模式 Play Mode **200/200** 断言通过，见 [运行证据](../../11-VerificationAndDebug/02-PlayModeValidation/Artifacts/CONTROLLER-TRIGGERS-20260926.txt)。生产脚本/输入资源与隔离工程哈希一致，主工程重编译无错误。旧 170/170 属特殊武器扩展时的 RT 绝对力度历史基线。
- 实物扳机、力度变化速度与 Android 蓝牙手感仍待设备验收。
