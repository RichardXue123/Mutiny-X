# Mutiny X 手柄操作手册

适用版本：`feature/controller_support` 当前版本。按常见 Xbox 手柄标记说明：**A 是南侧按钮，B 是东侧按钮**；其他手柄请按按钮位置对应。建议先在电脑上连接标准 Gamepad，再启动游戏。实物手柄与 Android 蓝牙手柄的手感仍待验收。

## 按键速查

| 输入 | 菜单 / 选择角色 | 选择行动后 / 战斗中 |
| --- | --- | --- |
| 十字键 | 移动当前界面的焦点；选人时在当前队伍的存活角色间移动 | 在行动面板选择跳跃、武器、结束回合等可用按钮 |
| 左摇杆 | 移动屏幕上的软件指针 | 未蓄力时移动软件指针；蓄力时表示**向后拉**的方向，投射物朝相反方向飞；松开摇杆保留最后的拉动方向 |
| 右摇杆 | 战斗画面允许时平移镜头 | 普通待命和手柄蓄力时平移镜头；受关卡边界限制 |
| LT 左扳机 | — | 选择跳跃或拉拽武器后进入瞄准；瞄准时降低力度，压得越深降得越快 |
| RT 右扳机 | — | 选择跳跃或拉拽武器后进入瞄准；瞄准时提高力度，压得越深升得越快 |
| A | 确认焦点或软件指针下的按钮；选定角色 | 蓄力时发射/起跳；点击型武器在指针位置放置/选目标；飞行中执行追加操作 |
| B | 返回上一级；若当前页面有“返回”按钮，执行该按钮 | 取消蓄力 → 返回行动面板 → 在允许时返回选人；退出弹窗中选择“继续” |
| Start | — | 打开现有退出弹窗 |

## 从主菜单开始

1. 用十字键移动焦点。初次按方向键会先定位到当前页面第一个可用按钮；之后按画面上的方向移动。焦点所在按钮显示原有悬停图像或说明。
2. 按 **A** 确认。选择“Play”后，可继续选择单人或双人模式、关卡。
3. 按 **B** 返回上一层。过渡动画进行中、被弹窗遮挡或仍在淡入的按钮不会响应手柄确认。

也可用左摇杆移动黄色十字软件指针，再按 **A** 操作指针下的可用按钮。若指针下没有按钮，第一次按 A 只定位焦点，不会直接执行默认选项。

## 选人、选武器与行动

1. 轮到人类玩家时，用十字键选中本队存活角色；焦点移动本身不会选定角色。按 **A** 打开该角色的行动面板。也可移动左摇杆指针至角色再按 A。
2. 在行动面板用十字键寻找可用按钮，按 **A** 选择“Throw Character”、普通武器或“End Turn”。面板仍在展开时，先等按钮出现并完成淡入。
3. 选择跳跃或拉拽武器后，先让 LT/RT 都松开，再按任一扳机进入瞄准。左摇杆表示**往后拉的方向**，发射方向与它相反：要往右上发射，就把左摇杆拉向**左下**；要向上跳，就把左摇杆拉向**下方**。
4. 用 **RT 提高力度、LT 降低力度**。按压深度决定变化快慢，满压默认每秒改变 50 个百分点；新瞄准从 0% 开始。松开两扳机后，瞄准状态和已调好的力度保持，可独立调整左摇杆方向或用右摇杆移动画布。画面显示力度条和百分比。同时按两个扳机时，按增减速度的差值调整；相同深度互相抵消。左摇杆回中保留最后的拉动方向。
5. 蓄力时按 **A** 才会发射或起跳，**无需一直按住扳机**；松开扳机不会发射。若尚未拉动左摇杆，或力度过小而不满足原有最小拖动距离，A 不会提交行动，蓄力回到待命。

使用上述蓄力方式的行动：角色跳跃，**Cherry Bomb、Dynamite、Boulder、Mine、Rum Bottle、Banana、Parachute Bomb、Pieces of Eight**，以及巫毒娃娃选定目标后的投掷。原有普通 `cannonball` 投掷入口也可使用同一瞄准方式；它并非额外新增的武器栏按钮。武器是否可选仍取决于角色的库存和本回合行动资格。发射成功后按原有规则扣除库存、进入行动结算；此时 B 不能撤回。

## 特殊武器

选中以下武器后，左摇杆移动画布上的软件指针，原版武器图标会跟随指针。右摇杆仍移动画布。点击型武器按一次 **A**，等同于鼠标在当前指针位置点击；持续按住 A 不会重复放置。

| 武器 | 手柄操作 |
| --- | --- |
| Anchor 锚 | 移动锚图标并按 A；锚落在指针的横坐标，初始高度沿用原版固定值。 |
| Seagull 海鸥 | 移动海鸥图标并按 A 选飞行高度；海鸥飞行中，每次新按 A 投下一枚。 |
| Tidal Wave 海啸 | 显示海啸图标；按 A 启动海啸。海啸仍从原版画布左侧、水面高度出发，指针位置不改变起点。 |
| Wooden Crate 木箱 | 移动木箱图标，依次按 A 放置三次。不可放的位置显示叉，按 A 不会放置或扣库存。 |
| Gunpowder Barrel 火药桶 | 与木箱相同，依次放置两次。 |
| Voodoo Doll 巫毒娃娃 | 移动娃娃图标至敌方角色按 A 绑定目标；随后用 LT/RT 进入瞄准和调力度，左摇杆向后拉，再按 A 投掷。 |
| Banana 香蕉 | 按普通方式投掷；飞行中再按一次 A 引爆。 |
| Parachute Bomb 降落伞炸弹 | 按普通方式投掷；飞行中移动左摇杆把风扇指针放在炸弹左侧或右侧，**重新按住 A** 扇风，松开即停止。左侧推动向右，右侧推动向左。 |
| Pieces of Eight 金币 | 按普通方式投出一枚；该枚结束后，松开双扳机，再用 LT/RT、左摇杆和 A 投下一枚，直至原有序列结束。 |
| Cannon 大炮 | 待命时左摇杆移动炮身；按 LT/RT 进入瞄准后，左摇杆改为后拉方向，扳机调拉环显示，A 开炮，B 返回部署。详见下节。 |

首次点击或投掷后进入的连续放置、投弹、引爆和扇风阶段仍属于同一武器行动，B 不能撤销已提交的动作。

## 大炮部署与开炮

1. 在行动面板选择 **Cannon**。此时左摇杆直接调整炮身部署位置；部署受角色上方范围圆和地形、箱体碰撞限制。右摇杆移动画布，炮身的世界位置保持。
2. 松开两扳机后，按 **LT 或 RT** 进入瞄准。炮身位置随之固定，左摇杆改为决定后拉方向：左下拉对应右上开炮。摇杆回中后保留炮口朝向；初次未调方向时沿用炮身当前朝向。
3. **RT 增加、LT 减少拉环的视觉蓄力**，松开扳机后保持。大炮实际炮弹初速固定，拉环是否拉满不会改变炮弹力度。
4. 按 **A** 开炮，不必一直按住扳机，也不要求拉环拉满。A 提交后扣一次库存，拉环按原有动画回弹，再发射独立炮弹。部署阶段直接按 A 不会开炮。
5. 瞄准时按 **B** 返回部署阶段，保留炮身位置和装备，复位拉环，不消耗库存。此时左摇杆可继续移炮；重新瞄准前需松开 LT/RT。部署阶段再按 B 返回行动面板。已经按 A 提交后不能撤回。

## 取消与退出

- **正在蓄力**：按一次 B 取消蓄力，清空本次力度，回到该武器或跳跃的待命状态，不消耗库存；如要重新蓄力，先松开 LT 和 RT，再按任一扳机。
- **武器或跳跃已选好、尚未蓄力**：按 B 回行动面板（以当前角色原有取消资格为准）。
- **行动面板**：允许重新选人时按 B 返回选人；角色行动已经锁定时不能回退。
- **退出弹窗**：按 Start 打开；弹窗完成淡入后按 B 选择“继续”，返回当前战斗。
- **A 与 B 同时按**：取消优先，不会误发射。

## 鼠标、触摸与断线

移动鼠标、点击鼠标、触摸屏幕或新按下键盘按键，可切回现有输入方式；再次操作手柄会切回手柄。正在进行的鼠标/触摸蓄力不会被手柄接管，正在进行的手柄蓄力也不会被鼠标移动抢走。手柄断连或应用失焦时，当前手柄蓄力会取消，不会当作松开发射。恢复连接后，先让摇杆回中、松开 LT/RT 和 A/B/Start，再继续操作。

## 兼容与限制

当前武器栏中的武器都可用手柄操作。大炮的鼠标/触摸方式仍沿用原有部署拖动和有效拉栓释放门槛；手柄 A 是明确的开炮确认。Credits 页的外链继续使用鼠标；返回按钮可用 B。

如果画面正在播放对话、镜头正在自动跟随、轮到 AI 或有退出弹窗，右摇杆不会抢走镜头控制。实物手柄的力度曲线、指针速度和 Android 蓝牙兼容性会在后续实机验收后调整。
