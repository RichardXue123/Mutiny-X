# 06.15 · Seagull

[返回上级模块](../README.md)

## 职责

记录海鸥路径、飞行、投弹和重复发射。

## 边界

参数和时序以原版证据为准。

## 逻辑摘要

- 首次点击选择飞行高度，从 x=-300 以 vx=10 向右飞。
- 飞行中每次点击都可投一枚弹，原版没有固定弹数；弹从 `(bird.x-10,bird.y)` 生成。
- 弹碰 Solid 爆炸 `50/50`，落水只销毁；鸟越界且活动弹清空后才结束。

来源：`Seagull.as`。规则：`SEA-*`，见 [完整审计](../IMPLEMENTATION_DETAILS.md#611-seagull)。
